# Icon artwork

`AppIcon.png` is the source artwork; `AppIcon.icns` is the macOS icon bundle. Regenerate the latter with `./scripts/make-icon.sh`.

Generated and edited using the built-in OpenAI image generation tool. The final edit replaces the equalizer bars with a speaker icon at the author’s request. No LG logo is used.

## Original prompt

Use case: logo-brand. Asset type: production macOS application icon for LG Sound, an independent open source utility controlling monitor speaker volume. Create a single beautifully crafted macOS app icon, 1024x1024 square composition: a rounded-square deep graphite tile with generous transparent margin outside it; centered sculpted silver ultrawide monitor outline with a short elegant stand, and a luminous cyan audio wave symbol inside the screen, three simple rounded vertical audio bars or sound arcs. Refined dimensional macOS icon, satin aluminum, restrained soft highlights, crisp silhouette readable at 32px. Straight-on view, centered, dark graphite and icy cyan palette, no letters, no text, no logos, no mockup, no surrounding objects. The icon itself occupies about 82% of the canvas with consistent clear margin. Transparent outside the tile.

## Final edit prompt

Edit this macOS app icon. Change only the three cyan vertical equalizer bars inside the monitor screen: replace them with a clear, elegant familiar speaker/volume symbol, a small stylized speaker cone on the left and two rounded sound wave arcs radiating to the right, centered as a single balanced symbol. Use the same luminous icy cyan material and restrained glow, crisp readable silhouette. Preserve the monitor, its silver frame and stand, the rounded graphite background tile, composition, proportions, lighting, and the transparent exterior exactly. No text, no letters, no logos, no equalizer bars. Keep the existing transparent background.
